RISC-V Instruction Quick Reference
Unit 00 · COD 2–3

這頁把 ch02 與 ch03 筆記裡出現過的 RISC-V instruction 集中在一起，方便查。 每一列最右邊的「講解」連到解釋它的那一頁，第一次看到某條 instruction 時建議點過去看完整說明。

怎麼讀語法欄。 rd 是寫入結果的 register（destination），rs1、rs2 是讀取的 register（source），imm 是直接寫在 instruction 裡的常數（immediate），off 是 load／store／jalr 用的 offset。 M[a] 表示 memory 中 address 為 a 的資料，PC 是目前這條 instruction 的 address。 格式欄是 instruction format（R、I、S、SB、UJ、U，整理在 ch02 page-61）。

算術#

指令語法做什麼格式講解
addadd rd, rs1, rs2rd = rs1 + rs2Rch02 p.06
subsub rd, rs1, rs2rd = rs1 − rs2Rch02 p.06
addiaddi rd, rs1, immrd = rs1 + imm（imm 12 bits，可為負，所以沒有 subi）Ich02 p.16
luilui rd, immrd = imm << 12（放 20-bit 常數到 bits 31–12），配 addi 做出 32-bit 常數Uch02 p.57
auipcauipc rd, immrd = PC + (imm << 12)Uch02 p.93
addw 等addw、subw、addiw、sllw、srlw、sraw、slliw、srliw、sraiw只對低 32 bits 運算，結果 sign-extend 成 64 bitsR／Ich02 p.93

乘法與除法（M extension）#

指令語法做什麼格式講解
mulmul rd, rs1, rs2128-bit 乘積的低 64 bitsRch03 p.10
mulhmulh rd, rs1, rs2乘積的高 64 bits，兩個都當 signedRch03 p.10
mulhumulhu rd, rs1, rs2乘積的高 64 bits，兩個都當 unsignedRch03 p.10
mulhsumulhsu rd, rs1, rs2乘積的高 64 bits，rs1 當 signed、rs2 當 unsignedRch03 p.10
div／divudiv rd, rs1, rs2rd = rs1 ÷ rs2 的商（signed／unsigned）；除以 0 不產生 exceptionRch03 p.15
rem／remurem rd, rs1, rs2rd = rs1 ÷ rs2 的餘數（signed／unsigned）Rch03 p.15

Logical 與 shift#

指令語法做什麼格式講解
and／andiand rd, rs1, rs2／andi rd, rs1, imm逐 bit AND，常用來套 maskR／Ich02 p.33
or／orior rd, rs1, rs2／ori rd, rs1, imm逐 bit OR，常用來把某些 bits 設成 1R／Ich02 p.34
xor／xorixor rd, rs1, rs2／xori rd, rs1, imm逐 bit XOR；xori rd, rs1, -1 就是 NOTR／Ich02 p.35
sllislli rd, rs1, imm左移 imm 位、右邊補 0，等於乘 2^immIch02 p.32
srlisrli rd, rs1, imm右移、左邊補 0（unsigned 的除以 2^imm）Ich02 p.32
sraisrai rd, rs1, imm右移、左邊補 sign bit（signed 右移後正負號不變）Ich02 p.32

Load 與 store#

指令語法做什麼格式講解
ldld rd, off(rs1)rd = M[rs1 + off]，8 bytes（doubleword）Ich02 p.12
sdsd rs2, off(rs1)M[rs1 + off] = rs2，8 bytesSch02 p.12
lb／lh／lwlb rd, off(rs1)讀 1／2／4 bytes，sign extension 到 64 bitsIch02 p.54
lbu／lhu／lwulbu rd, off(rs1)讀 1／2／4 bytes，zero extension 到 64 bitsIch02 p.54
sb／sh／swsb rs2, off(rs1)把 rs2 最右邊 1／2／4 bytes 寫進 memorySch02 p.54
lr.dlr.d rd, (rs1)rd = M[rs1]，同時登記 reservationRch02 p.63
sc.dsc.d rd, rs2, (rs1)reservation 還有效才寫 M[rs1] = rs2，rd = 0 成功、非 0 失敗Rch02 p.63

比較、分支與跳躍#

指令語法做什麼格式講解
beqbeq rs1, rs2, Lrs1 == rs2 就跳到 LSBch02 p.36
bnebne rs1, rs2, Lrs1 != rs2 就跳到 LSBch02 p.36
blt／bgeblt rs1, rs2, Lrs1 < rs2／rs1 >= rs2 就跳，當 signed 比SBch02 p.40
bltu／bgeubltu rs1, rs2, L同上，當 unsigned 比SBch02 p.41
slt／sltuslt rd, rs1, rs2rd = (rs1 < rs2) ? 1 : 0（signed／unsigned）Rch02 p.93
slti／sltiuslti rd, rs1, immrd = (rs1 < imm) ? 1 : 0（signed／unsigned）Ich02 p.93
jaljal rd, Lrd = PC + 4，然後跳到 L；呼叫 procedure 用 jal x1, LUJch02 p.43
jalrjalr rd, off(rs1)rd = PC + 4，然後跳到 rs1 + off；返回用 jalr x0, 0(x1)Ich02 p.43

Branch 與 jal 的 L 實際上被編成「離目前 PC 多遠」的 offset（PC-relative），細節在 ch02 p.58。

Floating point（F、D extension）#

結尾 .s 是 single precision、.d 是 double precision。運算都在 f0–f31 上做，但 load／store 的 address 仍用整數 register 算。

指令語法做什麼格式講解
flw／fldfld fd, off(rs1)fd = M[rs1 + off]（4／8 bytes）Ich03 p.33
fsw／fsdfsd fs2, off(rs1)M[rs1 + off] = fs2Sch03 p.33
fadd／fsub／fmul／fdiv .s／.dfadd.d fd, fs1, fs2fd = fs1 ＋ － × ÷ fs2Rch03 p.34
fsqrt.s／.dfsqrt.d fd, fs1fd = √fs1Rch03 p.34
feq／flt／fle .s／.dflt.d rd, fs1, fs2比較結果 1／0 寫進整數 register rd，再用 beq／bne 分支Rch03 p.34

Pseudoinstruction#

Assembler 接受、但硬體沒有的寫法，會被換成右邊的真 instruction。

寫法換成講解
li rd, immaddi rd, x0, imm；常數太大時拆成 lui + addich02 p.65
mv rd, rsaddi rd, rs, 0ch02 p.65
j Ljal x0, Lch02 p.65
ble rs1, rs2, Lbge rs2, rs1, L（兩個 operand 對調）ch02 p.65
not rd, rsxori rd, rs, -1ch02 p.35

容易搞混的幾組#

這組差在哪
add vs. addi第二個 operand 是 register 還是 instruction 裡的常數；只有 addi 能加常數
blt vs. bltu（bge／bgeu、slt／sltu 同理）同一串 bits 當 signed 還是 unsigned 比。全 1 當 signed 是 −1，當 unsigned 是最大的數
lb vs. lbu（lh／lhu、lw／lwu 同理）讀進來的資料不滿 64 bits，左邊補 sign bit 還是補 0
srli vs. srai右移時左邊補 0 還是補 sign bit；左移只有 slli 一種，因為右邊一律補 0
jal vs. jalr跳去的地方寫死在 instruction 裡（label），還是在執行時從 register 讀出來；返回、查表跳躍只能用 jalr
jal x1, L vs. jal x0, L要不要記 return address：前者是呼叫 procedure，後者是單純跳躍（j）
mul vs. mulh128-bit 乘積的低一半還是高一半；mul 不分 signed／unsigned，mulh 要分
div vs. rem商還是餘數，兩者是分開的 instruction
ld／sd vs. lr.d／sc.d一般存取，還是讓「讀、寫」之間不被別人插進來的 atomic 那一對
ld vs. fld讀進整數 register 還是 floating-point register
beq vs. flt.dbeq 本身就會跳；flt.d 只把比較結果寫進 register，還要再接一條 branch
