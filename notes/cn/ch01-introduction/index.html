What is the Internet#

The Internet: a “nuts and bolts” view (網路的硬體元件視角)#

元件說明對應 edge/core
Hosts (主機) = end systems (端系統)數十億台連網裝置（手機、筆電、伺服器、IoT裝置），跑 network apps，位於「edge」Edge
Packet switches轉送 Packet (一塊資料)的設備，也就是 routers（路由器）、switches（交換器）Core
Communication links傳輸媒介：fiber (光纖)、cotton (銅線)、radio (無線電)、satellite (衛星)；速度用 bandwidth (頻寬) 衡量連接 edge 與 core
Networks一群裝置、路由器、連結的集合，由某個組織（如 ISP）管理—
NOTE

ISP = Internet Service Provider（網際網路服務提供商）

就是幫你接上網際網路的公司，例如台灣的中華電信、台灣大哥大、遠傳等。你的手機、家用網路要連上「Internet」，都是先連到某個 ISP，再由 ISP 幫你把資料送到世界各地。

  • Internet: network of networks

  • protocols are everywhere

    • control sending, receiving of messages
    • 協定用途/位置
      4G手機連上 mobile network 的無線協定
      WiFi裝置連上 home/enterprise network 的無線協定
      Ethernet有線區域網路連線協定
      Skype應用層的視訊通話協定
      HTTP應用層的網頁瀏覽協定
      Streaming video串流影片的應用層協定
      TCP傳輸層協定，負責可靠傳輸
      IP網路層協定，負責封包routing/定址

  • Internet standards（網路標準）

    • RFC (Request for Comments)：Internet 協定的正式技術文件/規範
    • IETF (Internet Engineering Task Force)：負責制定並發布這些標準的組織

The Internet: a “services” view#

  • Infrastructure that provides services to applications: Web, streaming video (串流影片), multimedia teleconferencing (視訊會議), email, games, e-commerce, social media, inter-connected appliances, …
  • provides programming interface to distributed applications:
    • “hooks” allowing sending/receiving apps to “connect” to, use Internet transport service
    • provides service options (不只一種服務選項), analogous to postal service

What’s a protocal#

  • Protocols define the format, order of messages sent and received among network entities, and actions taken on message transmission, receipt.

Network edge: hosts, access network, physical media#

A closer look at Internet structure#

  • hosts: clients and servers
    • Clients（客戶端）：發起請求的一方，例如你的手機、筆電——通常間歇性上網、行動裝置多、IP可能會變動
    • Servers（伺服器）：提供服務、回應請求的一方，例如網站主機、串流影片伺服器
  • servers often in data centers：現代的 servers 大多不是單台機器，而是 大量集中放在資料中心（data center） 裡
  • Access networks (接取網路), physical media (物理媒介):
    • wired, wireless communication links
NOTE

Access network（接取網路） 指的是：把 host（你的裝置）實際連接到它所屬的 ISP、進而連上整個 Internet 的那一段網路，也常被稱為 “last mile”（最後一哩路），而 Access network 是靠 physical media 來實現的。

用位置來理解：

  • Network core
    • Interconnected routers（互聯的路由器）: Network core 的本質，就是大量 router 彼此互相連接所組成的網路。這些 router 的工作就是之前學過的：forwarding（轉送封包）——把封包從一個 router 傳到下一個 router，直到送達目的地。
    • Network of networks

Access networks and physical media#

Question

How to connect end systems to edge router?

我們知道要透過 Access network 把 end systems 連到 edge router，所以我們可以把 Access network 分成以下幾種：

  • residential access nets (住宅接取網路)
  • institutional access networks (school, company)
  • mobile access networks (WiFi, 4G/5G)

Access networks: cable-based access#

NOTE

一條 coax cable (同軸電纜) 的頻寬可以被切成很多頻道這樣就能一次傳輸很多種不同頻率的訊號

  • HFC: hybrid fiber coax（混合光纖同軸電纜）
    • 現代 cable 系統不是純電纜，而是「光纖（骨幹段）+ 同軸電纜（到府端）」混合架構，所以叫 hybrid
  • Asymmetric 傳輸速率
    • Downstream（下載）：40 Mbps – 1.2 Gbps
    • Upstream（上傳）：30-100 Mbps
    • 下載遠快於上傳，符合一般使用情境（觀看串流 > 上傳資料）
  • Homes share access network to cable headend（家戶共享）
NOTE

從圖就能看出：好幾戶人家的線都接在同一條主幹線上 意思是：你和鄰居共用同一段有限頻寬，鄰居用得越多（例如尖峰時段大家都在追劇），你分到的頻寬就可能變少

Access networks: digital subscriber line (DSL)#

DSL 代表使用電話線上網，好處是不用像 cable 跟其他人共享頻寬，但壞處是頻寬上限不高。

  • use existing telephone line to central office DSLAM
    • data over DSL phone line goes to Internet
    • voice over DSL phone line goes to telephone net
  • 24-52 Mbps dedicated downstream transmission rate
  • 3.5-16 Mbps dedicated upstream transmission rate

Access networks: home networks#

Wireless access networks#

Shared wireless access network connects end system to router

NOTE

不是靠實體電線傳輸，而是透過基地台（base station），也叫 access point（存取點，AP）——你家的 WiFi 分享器本身就是一種 access point

項目Wireless Local Area Network (WLAN, 無線區域網路 / WiFi)Wide-Area Cellular Network (廣域行動網路)
涵蓋範圍建築物內或周圍，約 100 英尺（約 30 公尺）數十公里
提供者使用者自行架設的路由器/存取點（Router / Access Point）行動網路電信業者（Mobile Network Operator）
連接技術標準IEEE 802.11b/g/n（WiFi）4G（Fourth Generation）行動網路，5G（Fifth Generation）已逐漸普及
傳輸速率11 Mbps / 54 Mbps / 450 Mbps數十 Mbps（10’s Mbps）
典型使用情境家裡、辦公室、咖啡廳等固定場所移動中、戶外、車上等廣域移動場景

Access networks: enterprise networks#

  • companies, universities, etc.
  • mix of wired, wireless link technologies, connecting a mix of switches and routers (we’ll cover differences shortly)
    • Ethernet: wired access at 100Mbps, 1Gbps, 10Gbps
    • WiFi: wireless access points at 11, 54, 450 Mbps

Access networks: data center networks#

  • high-bandwidth links (10s to 100s Gbps) connect hundreds to thousands of servers together, and to Internet

Host: sends packets of data#

host sending function:

  • takes application message
  • breaks into smaller chunks, known as packets, of length LLL bits
  • transmits packet into access network at transmission rate RRR
  • link transmission rate, aka link capacity, aka link bandwidth
packet transmission delay=L(bits)R(bits/sec)\text{packet transmission delay} = \frac{L \text{(bits)}}{R \text{(bits/sec)}}packet transmission delay=R(bits/sec)L(bits)​

Links: physical media#

  • bit: propagates between transmitter/receiver pairs
  • physical link: what lies between transmitter & receiver
  • guided media:
    • signals propagate in solid media: copper, fiber, coax
  • unguided media:
    • signals propagate freely, e.g., radio
Example (guided media)

Twisted pair (TP):

  • two insulated (絕緣) copper wires
    • Category 5: 100 Mbps, 1 Gbps Ethernet
    • Category 6: 10Gbps Ethernet
  • Coaxial cable (同軸電纜):
    • two concentric (同心圓排列) copper conductors
    • bidirectional
    • broadband:
      • multiple frequency channels on cable
      • 100’s Mbps per channel
  • Fiber optic cable (光纖電纜):
    • glass fiber carrying light pulses (光脈衝), each pulse a bit
    • high-speed operation:
      • high-speed point-to-point transmission (10’s-100’s Gbps)
      • low error rate:
        • repeaters spaced far apart
        • immune to electromagnetic noise (電磁波不會干擾)
Example (unguided media)
  • Wireless radio
    • signal carried in various “bands” in electromagnetic spectrum (訊號透過電磁頻譜裡面的不同頻傳輸)
    • no physical “wire”
    • broadcast (訊號會向四面八方發散), “half-duplex” (同一時間訊號只能單向 sender to receiver)
    • propagation environment effects:
      • reflection
      • obstruction by object (物體遮蔽)
      • Interference/noise
    • Radio link types:
      • Wireless LAN (WiFi)
        • 10-100’s Mbps; 10’s of meters
      • wide-area (e.g., 4G cellular)
        • 10’s Mbps over ~10 Km
      • Bluetooth: cable replacement
        • short distances, limited rates
      • terrestrial microwave (地面微波)
        • point-to-point; 45 Mbps channels
      • satellite
        • up to 45 Mbps per channel
        • 270 msec end-end delay
